I recently discussed Superpowers skills for Claude Code with a friend, who said they were too verbose, invoked subagents too often, and generated too large implementation proposals and code.

The same is true from my experience. It seems to have gained attention quickly, but it doesn't produce reliable, maintainable, production-ready code. It's useful for testing an idea ASAP, but you need a fat wallet.

So, I can stay: you need Superpowers LLM skills only in two cases:

1. You want to be the top one guy in burning tokens (Meta-style KPIs).

2. You want to 'copy' a well-built project: C++ compiler, PyTorch, etc. It's not bad: maybe you need to use just a small part of an existing project to reduce the size of dependencies.
